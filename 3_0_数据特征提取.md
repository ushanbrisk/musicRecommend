# 3.0 数据特征提取（详细）

## 概述

特征提取是将歌曲的原始数据（歌名、歌手、专辑、歌单、评论等）转换为 LLM 可理解的语义特征的过程。

## 特征提取流程

```
歌曲池 (songs) + 歌单信息 (song_playlist_agg) + 评论信息 (song_comment_agg)
                                    │
                                    ▼
                            【预聚合表】
                                    │
                    ┌───────────────┴───────────────┐
                    │                               │
                    ▼                               ▼
         song_playlist_agg               song_comment_agg
         (歌单名称聚合)                    (评论聚合)
                    │                               │
                    │         【特征生成】           │
                    └───────────────┬───────────────┘
                                    │
                                    ▼
                            music_features
                            (LLM 提取的特征)
```

## 预聚合表说明

### song_playlist_agg（歌曲-歌单预聚合）

**来源**：由 `songs` + `song_playlist` + `playlists` 通过 JOIN 聚合而来

**生成脚本**：
```bash
cd /home/luke/code_project/musicRecommend
~/miniconda3/envs/music/bin/python scripts/init_song_playlist_agg.py
```

**生成后验证**：
```sql
-- 检查数据完整性
SELECT
    COUNT(*) as total_songs,
    COUNT(*) FILTER (WHERE playlist_names IS NOT NULL AND array_length(playlist_names, 1) > 0) as songs_with_playlists,
    COUNT(*) FILTER (WHERE playlist_names IS NULL OR array_length(playlist_names, 1) = 0) as songs_without_playlists
FROM song_playlist_agg;

-- 查看样例数据
SELECT song_id, playlist_names, playlist_count
FROM song_playlist_agg
WHERE array_length(playlist_names, 1) > 0
LIMIT 5;
```

### song_comment_agg（歌曲-评论预聚合）

**来源**：由 MongoDB `comments` 集合聚合而来

**生成脚本**：
```bash
cd /home/luke/code_project/musicRecommend
~/miniconda3/envs/music/bin/python scripts/init_song_comment_agg.py
```

**数据处理说明**：
- 每首歌曲取评论按点赞数排序的前 5 条
- 每条评论截断到 200 字符
- 存储 `top_comments`（数组）和 `comment_summary`（拼接字符串）

**生成后验证**：
```sql
-- 检查数据完整性
SELECT
    COUNT(*) as total_songs_with_comments,
    AVG(comment_count) as avg_comment_count,
    AVG(avg_polarity) as avg_polarity
FROM song_comment_agg;

-- 查看样例数据
SELECT song_id, comment_count, top_comments, avg_polarity
FROM song_comment_agg
LIMIT 5;
```

## 特征生成方式

### 方式一：API 接口（在线）

启动后端服务后，通过 HTTP 请求触发：

```bash
# 批量生成（约 12.4 万首）
for i in {1..124}; do
  echo "Batch $i/124 started at $(date)"
  curl -s -X POST http://localhost:5000/api/features/generate \
    -H "Content-Type: application/json" \
    -d '{"batch_size": 1000}' > /dev/null
  echo "Batch $i/124 completed at $(date)"
  sleep 1
done

# 检查进度
PGPASSWORD=luke psql -h localhost -U postgres -d musicdb -c "SELECT COUNT(*) FROM music_features;"
```

**相关代码**：
- 路由：`backend/routes/recommend.py:176` (`POST /api/features/generate`)
- 服务：`backend/services/feature_service.py:78` (`batch_generate_features`)

### 方式二：Python 脚本（离线）

直接执行脚本，无需启动后端：

```bash
cd /home/luke/code_project/musicRecommend
~/miniconda3/envs/music/bin/python scripts/init_music_feature_vllm.py
```

**前置条件**：
1. 先启动 vLLM 服务：`bash scripts/start_vllm_servers.sh start`
2. 确保预聚合表已生成

**相关脚本**：
- `init_music_feature_vllm.py` - 单模型版本
- `init_music_feature_vllm_v2.py` - 第二版本
- `init_music_feature_vllm_v3.py` - 第三版本

## music_features 表结构

```sql
CREATE TABLE music_features (
    id SERIAL PRIMARY KEY,
    song_id INTEGER UNIQUE NOT NULL,
    genre VARCHAR(255),           -- 流派
    mood VARCHAR(255),            -- 情绪
    tempo VARCHAR(50),             -- 节拍：快/中/慢
    instruments TEXT,              -- 乐器
    scene TEXT,                    -- 场景
    language VARCHAR(50),          -- 语言
    era VARCHAR(50),               -- 年代
    description TEXT,              -- 描述
    emotional_tags TEXT,           -- 情感标签
    theme_keywords TEXT,           -- 主题关键词
    inherited_tags TEXT,           -- 继承自歌单的标签
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
